# Privacy policy

JSON Formatter does not collect or transmit personal data. It has no analytics,
telemetry, advertising, accounts, or remote services.

JSON documents are parsed and displayed locally in your browser. Their contents
are not sent to the developer or any third party. The extension reads page
content to detect JSON documents; it leaves other pages unchanged.

When you change the theme, the extension saves only the theme name under
`jf-theme` in the current site's local storage, when available. This preference
is specific to that site, may be visible to that site, and can be removed by
clearing the site's data. No JSON content is saved in local storage.

Copy buttons write JSON or a property path to your clipboard only when you
click them. The extension does not read your clipboard. Clicking an HTTP or
HTTPS link in a JSON value opens that destination in a new tab.

Firefox handles extension installation and updates through Mozilla Add-ons.
Mozilla's services and any websites you choose to visit have their own privacy
policies.

Questions: https://github.com/MohamedElashri/json-formatter/issues

Effective for version 1.0.2.
